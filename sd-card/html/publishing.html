Choose exactly which values get pushed to each integration. Columns are MQTT, InfluxDB and Home Assistant; tick a box to publish that parameter to that platform. Greyed cells are not applicable to that platform. Parameters the device gathers but does not normally send (previous value, recognition confidence, raw/rate for InfluxDB…) are listed here too — just tick them to start sending.

Turning parameters off, or using only send changed readings, reduces how much data the device pushes. Changes take effect after the next reboot.

Home Assistant entities read their value from the matching MQTT topic, so ticking a parameter in the Home Assistant column automatically keeps its MQTT topic on.
