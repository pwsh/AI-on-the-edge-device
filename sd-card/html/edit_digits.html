Digit ROI

CLICK HERE for usage description. More infos in documentation: ROI Configuration

Region Of Interest (ROI) for digit numbers can be defined on this page. If no digit numbers need to be processed, disable digit processing by deselecting "Digit ROI Processing".

By default, one number sequence is predefined and already selected in the drop-down "Number sequence". (A number sequence consists of one or more digit ROIs plus one or more analog counter ROIs that are processed together.) If you need more than one number sequence, add additional ones with the buttons next to the drop-down. Each number sequence is processed separately.

Position the digit ROIs over the digit numbers on the reference image, either by dragging them with the mouse or by entering the parameters in the fields below. To define ROIs properly, please check the documentation: ROI Configuration. It's very important to be really precise to have reliable processing. With the drop down "ROI" you can change between the different ROIs in the selected number sequence. To create new ROIs use "New ROI".

The order of the ROIs defines their position (and therefore the multiplication factor) within the reading sequence. Use the "Move ROI Lower" and "Move ROI Higher" buttons to change a ROI's position in the number sequence. The two multipliers shown below the ROI drop-down are: the factor from the position/order alone, and (on the right) that factor after the Decimal Shift setting is applied (an expert parameter on the configuration page, default: 0).

"Examine ROI" runs the neural network on just the selected ROI right now and shows the cropped image it analysed, the reading and the recognition confidence — a quick way to check a single digit without saving or waiting for a full round. "Pull camera image" captures and aligns a fresh frame from the camera and shows it in place of the stored reference image, so you can judge whether the reference image and alignment are still accurate (use "Show reference image" to switch back; Examine ROI then analyses whichever image is shown). Both use the live x/y/Δx/Δy values, so there is no need to save first.

After defining the digit ROIs, don't forget to save with the "Save Config" button!
NOTE: There is no need to perform a reboot after every saving or step. It's sufficient to reboot after all configuration steps (reference image, alignment, ROI configuration) are completed to activate new configuration.
