Step 1 / 7: Adjust Focus And Verify Flashlight

First, find a proper mounting position and, if needed, adjust the focus of the camera lens to get a sharp, crisp image. The live stream with the flashlight on can help with this. More details about adjusting the camera lens can be found here: Focus Adjustment
Also check that the flashlight does not create any disturbing reflections in the areas that will be processed. Besides the built-in flash LED, you can attach external LEDs to the device for better lighting. Please read the documentation if you'd like to use external LEDs: Installation Of External LEDs

NOTE: For this initial check, the flashlight intensity is set to the default (50%); you can change it in the next step. After changing it, you can return to this step to test with the new intensity.
The live stream is also available at any time from the normal web interface, even after setup is complete.
