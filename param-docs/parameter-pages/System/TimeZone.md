# Parameter `TimeZone`
Default Value: `CET-1CEST,M3.5.0,M10.5.0/3`

Time zone in POSIX syntax (Europe/Berlin = `CET-1CEST,M3.5.0,M10.5.0/3` - incl. daylight saving).
Select your region/city from the dropdown; the matching POSIX string (including daylight-saving
rules) is applied automatically. The list is generated from the IANA time zone database.
