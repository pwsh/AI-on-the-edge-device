# Parameter `ExternalLED`
Default Value: `enabled`

Master on/off switch for the **external** WS281x (NeoPixel) strip. When **disabled** the strip is not
driven at all - neither the capture flash nor the processing-stage colours - regardless of the other
External LED settings (the pin, colour and brightness are kept, so you can re-enable it later without
re-entering them).

Select **disabled** if you have no external LED strip connected.
