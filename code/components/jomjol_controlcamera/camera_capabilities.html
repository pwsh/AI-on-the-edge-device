Camera sensor capabilities

OV2640 / OV3660 / OV5640 / OV7670 / OV7725 — derived from the esp32-camera driver source and what this firmware applies. Reviewed 2026-05-31.  ✅ supported · ❌ stub/unsupported · ⭐ added by this project.

Usable with this firmware? Capture is JPEG, so a sensor must support on-chip JPEG: OV2640 / OV3660 / OV5640 are usable; OV7670 / OV7725 are not (no JPEG).

OV2640 · 2 MP

Max resolution: 1600×1200 (UXGA, 1.92 MP)
Auto focus: no
Frame sizes: 96×96 QQVGA 160×120 QCIF 176×144 HQVGA 240×176 240×240 QVGA 320×240 320×320 CIF 400×296 HVGA 480×320 VGA 640×480 SVGA 800×600 XGA 1024×768 HD 1280×720 SXGA 1280×1024 UXGA 1600×1200
Pixel formats: JPEG, RGB565, RGB888, YUV422, GRAYSCALE
Sharpness: ⭐ custom (no native); Denoise: no-op (forced 0).

OV3660 · 3 MP

Max resolution: 2048×1536 (QXGA, 3.15 MP)
Auto focus: no
Frame sizes: OV2640 list + FHD 1920×1080 QXGA 2048×1536
Pixel formats: JPEG, RGB565, RGB888, YUV422, GRAYSCALE, RAW
Auto-sharpness: firmware no-op; manual sharpness works.

OV5640 · 5 MP

Max resolution: 2560×1920 (QSXGA, 4.92 MP)
Auto focus: yes (driver/VCM; needs AF firmware + AF lens) — not exposed by this firmware
Frame sizes: OV3660 list + QHD 2560×1440 WQXGA 2560×1600 QSXGA 2560×1920
Pixel formats: JPEG, RGB565, RGB888, YUV422, GRAYSCALE, RAW
Auto-sharpness: firmware no-op; manual sharpness works.

OV7670 · 0.3 MP — not usable

Max resolution: 640×480 (VGA, 0.3 MP)
Auto focus: no
Frame sizes: up to VGA 640×480
Pixel formats: RGB565, RGB888, YUV422, GRAYSCALE — no JPEG, no RAW
Very limited: only AEC/AGC/AWB, mirror/flip, colorbar, framesize, pixformat.

OV7725 · 0.3 MP — not usable

Max resolution: 640×480 (VGA, 0.3 MP)
Auto focus: no
Frame sizes: up to VGA 640×480
Pixel formats: RGB565, YUV422, GRAYSCALE — no JPEG, no RAW, no RGB888
Has brightness/contrast/AEC/AGC/AWB; no saturation/sharpness/denoise/special-effect/WB-mode/quality.

API set_* functions not used by this firmware

  • set_colorbar — sensor test pattern (all support it); the only user-relevant capability never surfaced.
  • set_pixformat, set_pll, set_xclk — set once at camera init.
  • set_reg, set_res_raw — low-level register / raw-resolution escapes.
  • OV5640 autofocus (ov5640_af_init, ov5640_af_get_status, …) — present in the driver but not wired up.
